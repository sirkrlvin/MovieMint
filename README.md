🎬 MovieMint

A mini IMDB-style movie discovery app built with React and the TMDB API — 
a hands-on project for leveling up core software engineering fundamentals: 
REST APIs, HTTP request handling, API integration patterns, and state management.

✨ Overview
MovieMint lets users browse and discover movies using live data from The Movie Database (TMDB). 
It's built from the ground up with a clean separation between data fetching, state management, and presentation — the kind of architecture you'd want in a production app, not a tutorial throwaway.

🛠️ Built with React,Tailwind CSS & Node.js
